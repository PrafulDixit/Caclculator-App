# Calculator CLI

A minimal safe CLI calculator that evaluates arithmetic expressions.

Features:
- +, -, *, /, **
- Parentheses
- Unary plus/minus
- History command

Run:

```bash
python -m calculator_app.cli
```

Examples:

```
calc> 2 + 3 * (4 - 1)
11
calc> history
1: 2 + 3 * (4 - 1) = 11
calc> quit
```
